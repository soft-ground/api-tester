# Screenshots

Drop PNG screenshots here, then uncomment the image block near the top of the root
[README.md](../../README.md).

Recommended captures (the Fields view is the headline feature — lead with it):

| File | What to capture |
|------|-----------------|
| `fields-view.png` | A request with a JSON body, the **Fields** view open, showing required/optional badges and nested fields. |
| `scenario-run.png` | A scenario after **Run**, showing chained steps with pass/fail and extracted values. |
| `collections.png` | The APIs view: the collection tree on the left and the request builder on the right. |

Keep images reasonably sized (roughly < 300 KB, ~1400px wide) so the README stays light.
